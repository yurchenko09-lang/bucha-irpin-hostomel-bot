# Бот Бучанського району (Буча · Ірпінь · Гостомель)

Автоматично публікує в Telegram:

| Пост | Коли |
|---|---|
| ☀️ **Ранковий**: тривоги за ніч, погода, якість повітря, курс НБУ | щодня о ~7:00 |
| 📊 **Тривоги за тиждень**: кількість, тривалість, найдовша, порівняння з минулим тижнем | понеділок о ~9:00 |
| 🟠 **Погане повітря**: попередження, якщо AQI вищий за поріг | не частіше разу на день, 7:00–22:00 |

Працює безкоштовно на GitHub Actions: запускається кожні 30 хв, сам вирішує, чи час щось публікувати, і пам'ятає зроблене у `state.json`.

**Джерела даних:** Open-Meteo (погода й повітря, без ключа), НБУ (курс, без ключа), alerts.in.ua (тривоги, потрібен токен).

---

## Налаштування (≈15 хв)

### 1. Бот у Telegram
1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → дайте назву → отримаєте **токен** (`123456:ABC...`).
2. **Для тестів поки без каналу:** напишіть своєму боту будь-що, потім відкрийте в браузері
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайдіть `"chat":{"id": 123456789` — це ваш **CHAT_ID**. Пости приходитимуть вам в особисті.
3. **Коли буде канал:** додайте бота адміністратором із правом публікації, а `CHAT_ID` змініть на `@назва_каналу`.

### 2. Токен тривог (необов'язково, але бажано)
Подайте заявку на [devs.alerts.in.ua](https://devs.alerts.in.ua/). Поки токена немає, бот працює без блоку тривог і без тижневої статистики.

### 3. Репозиторій на GitHub
1. Створіть новий репозиторій (краще **Public**: для публічних репозиторіїв Actions безкоштовні без ліміту; токени все одно захищені в Secrets).
2. Завантажте туди всі файли з цієї папки (Add file → Upload files; або через `git push`).
   Папка `.github` прихована, і Windows/браузер можуть її пропустити. Надійніше так: **Add file → Create new file**, у назві введіть `.github/workflows/bot.yml` і вставте вміст цього файлу.
3. **Settings → Secrets and variables → Actions → New repository secret**, додайте:
   - `BOT_TOKEN` — токен від BotFather
   - `CHAT_ID` — ваш ID або `@назва_каналу`
   - `ALERTS_TOKEN` — токен alerts.in.ua (коли отримаєте)
4. **Settings → Actions → General → Workflow permissions** → оберіть **Read and write permissions** → Save (потрібно, щоб бот зберігав `state.json`).

### 4. Перевірка
**Actions → Bucha region bot → Run workflow**:
- `force` = `morning`, `dry_run` = ✅ → у лозі побачите текст поста, нічого не надсилається;
- зніміть `dry_run` → пост прийде в Telegram.

Далі все працює саме.

## Налаштування в `config.json`

| Параметр | Що змінює |
|---|---|
| `weather_point` | координати для погоди й повітря (зараз — центр між трьома містами; вони поруч, тож прогноз однаковий) |
| `alerts.match_words` | які тривоги рахувати: за збігом у назві громади/району |
| `alerts.count_whole_oblast` | рахувати тривоги на всю Київську область (`true`) |
| `morning.hour` | година ранкового поста |
| `morning.night_from_hour` | з якої години рахується «ніч» |
| `weekly.weekday` / `hour` | день (0 = пн) і година тижневої статистики |
| `air.aqi_threshold` | поріг попередження (European AQI: 60+ погана, 80+ дуже погана) |
| `weather_warnings` | пороги для «⚠️ Увага»: пориви вітру, спека, мороз, опади |
| `currencies` | валюти НБУ, напр. `["USD", "EUR", "PLN"]` |

## Корисно знати
- GitHub запускає розклад із затримкою 5–20 хв, тож пост вийде приблизно о 7:05–7:30.
- Якщо якесь джерело не відповідає, пост виходить без цього блоку; якщо не відповідає жодне — не виходить, і бот спробує знову за 30 хв.
- Якість повітря — модельні дані (Copernicus CAMS через Open-Meteo), а не показники конкретної станції: це загальна картина, не точний замір на вулиці.
- GitHub вимикає розклад у репозиторіях без активності 60 днів. Бот щодня комітить `state.json`, що має зараховуватися як активність; якщо колись розклад вимкнеться — у вкладці Actions буде кнопка «Enable workflow».
